# Decidia

L'IA qui ose te dire non — SaaS d'aide à la décision (modèles mentaux + Océan Bleu).

## Démarrer

```bash
npm install
npm run dev      # http://localhost:3000
npm run lint && npx tsc --noEmit && npm run build
```

Le design system est visible sur `/design` (mode sombre par défaut, bascule clair/sombre).

Stack : Next.js 15, TypeScript strict, Tailwind v4, Radix, Framer Motion, Lucide.
